# 📄 DIEGOTECHPDF

**Gerenciador e Conversor de Arquivos PDF para Windows**

O **DIEGOTECHPDF** é um software desktop desenvolvido em Python com o objetivo de facilitar a organização, união e conversão de documentos PDF.

O projeto surgiu da necessidade de reunir diferentes funcionalidades em uma única ferramenta, oferecendo praticidade, rapidez e uma interface simples e intuitiva.

## 🚀 Funcionalidades

### 🔗 Juntar PDFs
- Una vários arquivos PDF em um único documento.
- Organize a sequência dos arquivos com numeração automática.
- Altere a ordem dos documentos facilmente.
- Visualize a primeira página de cada PDF.
- Confira a sequência antes de salvar o arquivo final.

### 🖼️ Converter imagens em PDF
- Converta imagens JPG, PNG, JPEG, BMP e outros formatos.
- Ajuste a orientação da página (retrato ou paisagem).
- Configure o tamanho e o preenchimento da imagem.
- Escolha a qualidade de exportação (150 ou 300 DPI).
- Visualize o resultado antes da conversão.

### 📝 Converter Word/ODT em PDF
- Converta documentos DOC, DOCX e ODT.
- Reúna vários documentos convertidos em um único PDF.
- Compatível com Microsoft Word ou LibreOffice instalado.

## 📥 Download

Acesse a seção **Releases** deste repositório e baixe a versão mais recente do programa:

**DIEGOTECHPDF.exe**

Não é necessário instalar o Python para utilizar o executável.

## 💻 Requisitos

- Sistema operacional Windows.
- Microsoft Word ou LibreOffice para conversão de documentos Word/ODT.
- Espaço disponível para salvar os arquivos convertidos.

## 🛠️ Tecnologias utilizadas

- Python
- CustomTkinter
- pypdf
- Pillow
- PyMuPDF
- PyInstaller
